## Shared gates (both countries)

| Gate | Requirement |
|------|-------------|
| **G1 — Egypt** | Finished product registered with **EDA** for export; valid **CPP (WHO format)** + GMP; batch **CoA**; **Export Ready** stock in Alexandria warehouse |
| **G2 — Destination** | Product **marketing authorization** (or interim import permit) in target country; **manufacturer/site** accepted by destination NMPB |
| **G3 — Buyer** | Licensed **wholesale importer**; signed distribution agreement; proforma accepted |
| **G4 — Payment** | Instrument agreed **before** dispatch (see per-country payment section) |
| **G5 — Shipment** | Commercial invoice, packing list, CoA, GDP cold-chain records if applicable; route-specific pre-clearance (Libya **ACI**, etc.) |

## Qualified buyer scorecard (use for both)

Score each importer 0–2 per row; **≥14/20** = pursue; **≥16** = priority for first shipment.

| Criterion | 0 | 1 | 2 |
|-----------|---|---|---|
| Wholesale/pharma import licence (current) | None / expired | Renewing | Valid + verifiable |
| Prior Egypt imports | None | Sporadic | Regular Egypt lines |
| Registration capability | Cannot file | Uses consultant | In-house RA |
| Cold chain / GDP | None | Partial | Documented GDP |
| Payment track record | Unknown | Mixed | Bank refs / LC history |
| Geographic reach | Single city | Multi-city | Matches your target states |
| Port/border access | Unclear | One corridor | Confirmed corridor + broker |
| Political / FX risk (country-specific) | High exposure | Managed | Mitigated structure agreed |

## Document index (Egypt origin — all exports)

| Document | Purpose |
|----------|---------|
| EDA **CPP** (WHO certificate scheme) | Proves marketing authorization in Egypt |
| **GMP** certificate (manufacturing site) | Site acceptance abroad |
| **Free Sale Certificate** | Often requested with CPP |
| CTD modules (quality, clinical if Rx) | Destination registration |
| **Batch CoA** + release documentation | Per shipment |
| Arabic translations | Libya (mandatory for customs); Sudan (often required) |
| Proforma / contract | Commercial terms |
| Insurance + Incoterms | Risk allocation (prefer **CIF/CIP** with named port) |
