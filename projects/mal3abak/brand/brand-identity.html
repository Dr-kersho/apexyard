✗
English-only — Arabic is never an afterthought

05 — Logo Usage Rules

✓ Do

✓
Use full-colour lockup on dark backgrounds
✓
Maintain clear space = height of "M" on all sides
✓
Use icon-only mark below 120px or in circular crops
✓
Use white-only t-shirt variant for single-colour screen prints

✗ Don't

✗
Change any colour — never swap orange for another accent
✗
Add drop shadows or effects not defined here
✗
Remove the Arabic subtitle from any full-lockup usage
✗
Use below 32px (use favicon-level icon instead)
